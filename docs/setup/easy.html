Why Railway

Click deploy, set a few secrets, get a public HTTPS link for the dashboard. Railway restarts crashes and can redeploy when GitHub updates.

Already have a VPS or prefer local? Use the Advanced guide.

Deploy on Railway (paper)

  1. Create a Railway account

    Sign up with this link (supports the project): railway.com?referralCode=SCj9lN. GitHub login is easiest.

  2. New project from GitHub

    New Project → Deploy from GitHub → pick CryptoGnome/dlmmbot (or your fork). Private repos need Railway access granted.

  3. Two services, same repo

    ServiceStart commandPublic?
    farmer npm run run No
    dash npm run dash:build && npm run dash Yes — generate a domain

    Both need Node 20+. Railway runs npm install on deploy.

  4. Shared variables (paper-safe)

    FARMER_MODE=paper
RPC_URL=https://api.mainnet-beta.solana.com
DASH_TOKEN=pick-a-long-random-password
DASH_PORT=8787

    Leave WALLET_PRIVATE_KEY empty for paper. FARMER_MODE=paper will not live-trade even if config says live.

    Never paste keys into Discord or screenshots. Never use your main wallet.

  5. Attach a volume

    SQLite lives under data/. Mount a volume at /app/data (or app root + /data) so redeploys don’t wipe history.

  6. Deploy

    Wait for green. On dash: Settings → Networking → Generate domain.

Open the dashboard

Use the dash HTTPS URL (https://….up.railway.app). Enter the same DASH_TOKEN. Works from your phone — token still required.

Auto-updates

Connect Railway to GitHub so pushes to master redeploy.

  • Paper: auto-deploy is fine.
  • Live: prefer deploying after CI is green, or deploy manually.

Keys & APIs

Burner wallet — Phantom

  1. Install Phantom.
  2. Create a new account.
  3. Fund only SOL you’re willing to lose.
  4. Export Private Key (base58) → Railway WALLET_PRIVATE_KEY.

Close the export screen. Don’t screenshot it.

Private RPC

Live needs a private endpoint (Helius, QuickNode, etc.). 

RPC_URL=https://your-provider-url-here

Going live

Real SOL. Burner only. One farmer process per wallet.

  • Paper looked sane
  • Burner + private RPC + Jupiter in Railway vars
  • FARMER_MODE=live
  • [exec] mode = "live" in config
  • Redeploy so both switches are live

Live requires both env and config. One alone stays safe.

Cost
