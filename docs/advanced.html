Local install (paper)

NeedGet itCheck
Node.js 20+ nodejs.org node -v
Git git-scm.com git --version

  1. Clone & install

    git clone https://github.com/CryptoGnome/meteora-farmer.git
cd meteora-farmer
npm install

    better-sqlite3 compiling is normal. On Windows you may need VS Build Tools (C++).

  2. Create .env

    cp .env.example .env
    FARMER_MODE=paper
RPC_URL=https://api.mainnet-beta.solana.com

  3. Force paper in config.toml

    [exec]
mode = "paper"

    Live needs both this and FARMER_MODE=live.

  4. Run

    npm run run

    Other terminal:

    npm run status
npm run halt

Commands

npm run scan | vet | run | status | halt | force-close | test
npm run dash:build && npm run dash

Local dashboard

DASH_TOKEN=pick-a-long-random-password
DASH_PORT=8787
npm run dash:build
npm run dash

Open http://localhost:8787 with that token.

Keys & going live

Same as the easy guide: Phantom burner → WALLET_PRIVATE_KEY, private RPC, Jupiter key.

# .env
FARMER_MODE=live
RPC_URL=https://your-private-rpc
JUPITER_API_KEY=…
WALLET_PRIVATE_KEY=…
# config.toml
[exec]
mode = "live"

Burner only. One farmer process per wallet/DB.

PM2 on a VPS (always-on)

This is how an operator box stays up without Railway.

npm install -g pm2
pm2 start deploy/ecosystem.config.cjs --only meteora-farmer
pm2 start deploy/ecosystem.config.cjs --only meteora-dash
pm2 save
pm2 startup
pm2 logs meteora-farmer

deploy/ecosystem.config.cjs also defines meteora-deploy (git pull watcher) — start that only if you want auto-updates from master.

Auto-deploy on your server

pm2 start deploy/ecosystem.config.cjs --only meteora-deploy
pm2 save

When origin/master advances, the watcher pulls, typechecks/tests, rebuilds the dash if needed, and restarts apps — same idea as Railway’s “deploy on push,” but you own the machine.

Don’t SCP over a dirty tree and expect the pill to say CURRENT — push + pull (or let meteora-deploy do it).

Dashboard from outside your LAN

Unlike Railway’s public HTTPS URL, a home/VPS dash needs one of:

  • Tailscale / ZeroTier — easiest private access from your phone
  • Cloudflare Tunnel — public HTTPS without opening ports
  • Reverse proxy + HTTPS (Caddy/Nginx) on a VPS with a domain

Don’t expose :8787 raw to the internet without a strong DASH_TOKEN (and preferably HTTPS).
